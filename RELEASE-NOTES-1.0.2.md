# DBWox 1.0.2 — Release Notes

## Bahasa Indonesia

**DBWox 1.0.2 — Yang Baru**

- **Query Editor:** SQL Outline, expand/collapse query, autocomplete lebih lengkap, serta dukungan file SQL besar.
- **SQL Problems:** validasi tabel/kolom, deteksi kolom ambigu, dan quick fix melalui intentionBulb atau **Alt+Enter**.
- **Database Explorer:** mode verbose dengan detail kolom, keys, dan indexes; refresh background serta penyimpanan posisi treeview.
- **Pencarian:** Find Usages, Search Database Objects, panel Property, dan navigasi langsung ke objek.
- **Export/Import:** Function Mapping berbasis CSV, perluasan terjemahan view dan CTE, serta pemilihan dependensi view.
- **SQL Dump:** cakupan objek lebih lengkap, pengurutan dependensi, dan format routine yang lebih rapi.
- **Optimizer & Tampilan:** skor dan rekomendasi Before/After, penyempurnaan tema Light/Dark, preview SQL berwarna, dan splash screen baru.

*Dukungan lintas database mengikuti kemampuan engine dan izin akses metadata.*

---

## English

**DBWox 1.0.2 — What's New**

- **Query Editor:** SQL Outline, query folding, expanded autocomplete, and large SQL file support.
- **SQL Problems:** table/column validation, ambiguous column detection, and quick fixes through intentionBulb or **Alt+Enter**.
- **Database Explorer:** verbose mode with columns, keys, and indexes; background refresh and saved tree state.
- **Search:** Find Usages, Search Database Objects, a Property panel, and direct object navigation.
- **Export/Import:** CSV-based Function Mapping, extended view and CTE translation, and view dependency selection.
- **SQL Dump:** broader object coverage, dependency ordering, and cleaner routine formatting.
- **Optimizer & Appearance:** Before/After scores and recommendations, improved Light/Dark themes, syntax-colored SQL previews, and an updated splash screen.

*Cross-database support depends on engine capabilities and metadata access permissions.*
